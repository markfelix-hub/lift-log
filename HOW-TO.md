# Your steps (about 20 minutes)

1. Make a folder on your computer called `lift-log`. Put these three files in it:
   - `reference-gymlog.html`
   - `seed-history.json`
   - `BRIEF-for-Claude-Code.md`
2. Open Claude Code in that folder (desktop app: start a new task, choose the folder).
3. Paste this as your first message:

   > Read BRIEF-for-Claude-Code.md and do everything in it. The reference page and seed history are in this folder. Ask me before you create any accounts. I do not have a GitHub account yet, so tell me exactly what to click.

4. Create a free GitHub account when it asks (github.com). Claude Code will do the rest and ask you to approve the deploy.
5. Open the URL it gives you on your phone.
   - iPhone: Safari, then Share, then "Add to Home Screen".
   - Android: Chrome, then the menu, then "Install app".
6. Open it once on Wi-Fi so it saves itself for offline use. Then switch on airplane mode and check it still opens.
7. After your first gym session, tap History, then Export backup, and keep the file somewhere safe.
